# Route A: embedding-conditioned stimulus readout

Implements paper Section **5.6.1 - Embedding-only stimulus readout**
(Route A, embedding-conditioned variant): **Figures 5 and 6**, and the
feature-family ablation in **Appendix Table/Fig. B1**.

## Scientific purpose

Predicts a behaviourally-grounded, target-conditioned visual search
**complexity score** for an NSD image and a COCO-Search18 target category,
directly from image embeddings, without fMRI:

- **DINOv2** ViT-L/14 CLS tokens, all 24 transformer blocks, averaged into
  3 tiers (early/mid/late, mirroring the visual cortex hierarchy) -> 3x1024-d.
- **CLIP** ViT-L/14 (OpenCLIP, LAION-2B) image embedding -> 768-d.
- Target conditioning: a learned category embedding plus a prompt-ensembled
  **CLIP text** embedding, combined via **FiLM** modulation of the image
  representation (:mod:`shared.complexity_head`, reused unmodified by Route B).
- A heteroscedastic MLP head outputs a mean complexity estimate mu (trained
  on category-residualised targets) and a predictive log-variance; the
  category mean is restored to obtain the final complexity score.

Fig. 5 illustrates this pipeline; it is a hand-drawn schematic and is not
generated by any script here.

## Feature-family ablation (Appendix Fig./Table B1)

Instead of concatenating DINO and CLIP features, `--features clip_only` or
`--features dino_only` uses each feature family individually, isolating its
contribution. See `model.select_features` and `training.py --features`.

## Inputs

None of these locations are hardcoded; every command below takes them as
flags.

| Flag | Contents |
| --- | --- |
| `--nsd-root` | NSD/Algonauts-2023 data tree. Only used to enumerate each subject's training image filenames (to map an NSD image ID to its embedding row); no fMRI data from this tree is used by this component. |
| `--dino-dir` | `{subject}_dino_layers.npy` files written by `extract-features`. |
| `--clip-img-dir` | `{subject}_clip_img.npy` files written by `extract-features`. |
| `--clip-text-path` | The prompt-ensembled CLIP text embeddings `.npz` file written by `extract-features`. |
| `--complexity-csv` | The target-conditioned complexity ranking (image, task, score), produced by the `complexity/` component. |
| `--out` | Output root for checkpoints, metrics, and figures. |

DINOv2 weights download via `torch.hub` (respects `TORCH_HOME`); CLIP
weights download via OpenCLIP (respects `HF_HOME`). See the repository's
data-setup documentation for recommended cache locations.

## Outputs

Checkpoints, metrics JSON, and figures are written under `--out`; none are
committed to this repository (see `.gitignore`). A run reproducing the
paper numbers writes:

- `<out>/checkpoints/route_a_embedding_{features}_{arch}_noise{noise}_fold{k}of{n}.pt`
  (evaluation-safe, holds out fold `k`) and `..._deploy_only.pt` (trained on
  all data, not for evaluation).
- `<out>/metrics_route_a_embedding_{features}_{arch}.json` - global metrics
  (Table 6 / Appendix Table B1).
- `<out>/per_subject_metrics_route_a_embedding_{features}_{arch}.json` and
  `<out>/figures/route_a_embedding_{features}_{arch}_per_subject_bar.{png,pdf}`
  - per-subject metrics and bar chart (Fig. 6 / Appendix Fig. B1).
- `<out>/figures/route_a_embedding_{features}_{arch}_{calibration_scatter,category_bars}.{png,pdf}`.

## Reproducing the paper results

```bash
NSD_ROOT=/path/to/algonauts_2023_challenge_data
FEATURES=/path/to/feature/cache      # writable cache dir, can be shared across runs
CSV=/path/to/full_ranking_M2_n_studentT.csv
OUT=/path/to/output/root

# 1. Extract and cache DINOv2 + CLIP embeddings (once; skips subjects already done).
python -m route_a.embedding extract-features \
  --nsd-root "$NSD_ROOT" --dino-dir "$FEATURES/dino" --clip-img-dir "$FEATURES/clip_image" \
  --clip-text-path "$FEATURES/clip_text/clip_text_embeddings.npz"

# 2. Train the main model: 5-fold CV, arch=small, both feature families (Fig. 5/6, Table 6).
python -m route_a.embedding train \
  --nsd-root "$NSD_ROOT" --dino-dir "$FEATURES/dino" --clip-img-dir "$FEATURES/clip_image" \
  --clip-text-path "$FEATURES/clip_text/clip_text_embeddings.npz" --complexity-csv "$CSV" --out "$OUT" \
  --arch small --features all --folds 5 --epochs 100 --noise 0.0

# 3. Train the feature-family ablation (Appendix Fig./Table B1).
python -m route_a.embedding train --features clip_only --arch small --folds 5 --epochs 100 --noise 0.0 \
  --nsd-root "$NSD_ROOT" --dino-dir "$FEATURES/dino" --clip-img-dir "$FEATURES/clip_image" \
  --clip-text-path "$FEATURES/clip_text/clip_text_embeddings.npz" --complexity-csv "$CSV" --out "$OUT"
python -m route_a.embedding train --features dino_only --arch small --folds 5 --epochs 100 --noise 0.0 \
  --nsd-root "$NSD_ROOT" --dino-dir "$FEATURES/dino" --clip-img-dir "$FEATURES/clip_image" \
  --clip-text-path "$FEATURES/clip_text/clip_text_embeddings.npz" --complexity-csv "$CSV" --out "$OUT"

# 4. Evaluate: global metrics (Table 6 / Appendix Table B1) and per-subject (Fig. 6 / Appendix Fig. B1).
for FEATURES_NAME in all clip_only dino_only; do
  GLOB="$OUT/checkpoints/route_a_embedding_${FEATURES_NAME}_small_noise0.00_fold*of5.pt"
  python -m route_a.embedding evaluate-global \
    --nsd-root "$NSD_ROOT" --dino-dir "$FEATURES/dino" --clip-img-dir "$FEATURES/clip_image" \
    --clip-text-path "$FEATURES/clip_text/clip_text_embeddings.npz" --complexity-csv "$CSV" --out "$OUT" \
    --checkpoint-glob "$GLOB"
  python -m route_a.embedding evaluate-per-subject \
    --nsd-root "$NSD_ROOT" --dino-dir "$FEATURES/dino" --clip-img-dir "$FEATURES/clip_image" \
    --clip-text-path "$FEATURES/clip_text/clip_text_embeddings.npz" --complexity-csv "$CSV" --out "$OUT" \
    --checkpoint-glob "$GLOB"
done
```

Noise augmentation (`--noise`) was only used to measure its effect on
training and is **not** part of the reported model; all commands above use
`--noise 0.0`.

(Per-subject means are averaged from the `pearson_full`/`spearman_full`

it was consolidated into the `--features` flag above; commands 3-4 reproduce
